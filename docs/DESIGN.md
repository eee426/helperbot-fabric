# 采购机器人（Helper Bot）设计文档

> Fabric 1.21.11 · 纯服务端模组 · 2026-10-31 初版

## 1. 目标

生存后期做大工程时，常常卡在"这次要用、量不小、又不值得造机器"的刁钻材料上。
本模组在服务器里放一个**真实的机器人玩家**：玩家给它工具和材料，下达采集任务，它像真人一样走路、挖掘、消耗耐久，把东西采回来。

**核心原则：不作弊、不越界、不犯傻。**

- 不凭空产生资源：所有产出都来自世界里真实存在的方块，耗时、耐久照原版计算。
- 只用玩家给的东西：机器人不能自己拿取任何物品，只能使用背包里玩家放进去的。
- 不碰玩家的东西：保护区、移动禁区、放置记录多层保护。
- 不接大模型：全部是确定性逻辑，可解释、可预测。

## 2. 运行环境

- 纯服务端模组，安装在服务器（或单人存档的内置服务端）上，玩家客户端不需要安装。
- 背包编辑界面使用原版箱子界面，原版客户端可以直接打开。
- 开发阶段先在单人存档里测试，之后部署到专用云服务器。
- 兼容 Carpet：不依赖它的内部代码，只参考它的假人实现思路。

## 3. 总体架构

```
指令层        /bot ...                     （第 5 节）
   ↓
规划器        目标 → 子目标 → 计划，算成本   （第 7 节）
   ↓
计划确认      发给玩家，确认后才执行
   ↓
定位器        已加载区块扫描 + 原版 locate 接口（结构、群系）
   ↓
执行器        行为状态机：寻路、挖掘、使用物品、合成……
   ↓
寻路          粗略路线 + 局部 A*，直接控制坐标（第 8 节）
   ↓
守卫          所有操作在落地前都要过一遍保护规则（第 9 节）
```

## 4. 机器人实体

- 服务端假玩家（`ServerPlayer` 子类 + 虚拟网络连接），参考 Carpet 的做法。
- 每个玩家可以有一个机器人，第一版只支持一个全局机器人。
- **右键机器人**：打开它的背包界面（4 行箱子界面：主背包 27 格 + 快捷栏 9 格；第 5 行放盔甲 4 格 + 副手 1 格）。
- **不计入睡觉人数**：机器人不阻止跳过夜晚。
- **死亡**：跟随服务器的规则（你们开了死亡不掉落）。复活后汇报，任务暂停。
- **苦力怕不把它当目标**：这是唯一的"小作弊"，用来保护地形（防止它把苦力怕引到基地）。
- **被怪物追的时候不回基地**。

## 5. 指令

| 指令 | 作用 |
|---|---|
| `/bot spawn` / `/bot remove` | 召唤或移除机器人 |
| `/bot get <物品> [数量] [mode]` | 下达采集任务，mode 是 `safe` / `normal` / `aggressive` |
| `/bot confirm` / `/bot cancel` | 确认或取消计划 |
| `/bot status` | 当前任务、进度、背包概况 |
| `/bot come` | 回到玩家身边 |
| `/bot protect` | 保护你所在的整个区块（再输一次取消）；聊天里有 [撤销] [显示边界] 按钮 |
| `/bot protect show` | 用粒子标出附近保护区块的边界（15 秒） |
| `/bot protect list` | 列出这个维度的保护区块 |
| `/bot restrict` | （管理员）查看临时限制；默认全关 |
| `/bot restrict block <方块>` | （管理员）开/关"不挖也不放这种方块"，例如 `minecraft:obsidian` |
| `/bot restrict portals on\|off` | （管理员）开/关"不被任何传送门传走" |
| `/bot log` / `/bot undo` | 查看最近操作，撤销上一个任务破坏的方块 |
| `/bot debug path` | 用粒子显示计划路线 |

## 6. 资源规则："只用玩家给的东西"

- **输入**：工具、燃料、搭路方块、合成材料，全部来自玩家放进背包的物品。
- **产出**：只收集任务目标物品。开路时挖到的其他方块默认丢弃，可以配置为保留当作搭路材料。
- **合成和熔炼**：只能用背包里已有的材料。可以通过开关关闭；关闭后缺什么就直接报告"请给我 X"。
- **不开任何容器**，包括箱子、木桶、潜影盒。

## 7. 规划器（知识自动生成）

服务器启动时，从游戏数据自动建立"获取知识"：

| 数据 | 用途 |
|---|---|
| 方块战利品表 | 挖这个方块会掉什么、需要什么工具或附魔（精准采集、剪刀） |
| 合成、熔炼配方 | 能不能用已有材料做出来 |
| 生物群系地物配置 | 哪些群系会生成这种方块 |
| 结构模板 | 哪些结构里含有这种方块 |
| 少量手写规则 | 用桶装液体、剪南瓜、刷可疑方块、珊瑚必须在水下等 |

规划流程：目标 → 列出所有获取途径 → 递归检查工具和材料够不够 → 估算成本（距离、耗时、耐久、危险） → 选成本最低的路线 → 生成计划，交给玩家确认。

做不到时**诚实失败**，说明原因，比如"缺少精准采集工具"或"5000 格内没有樱花林"。

## 8. 寻路与移动

### 8.1 直接控制坐标

服务端每个游戏刻直接设置机器人的精确坐标，不去模拟按键。为了保持"不作弊"，移动必须遵守以下约束：

- 每刻水平位移不超过原版速度：走路约 0.216 格/刻，疾跑约 0.281 格/刻。
- 每一步都要通过原版碰撞检测，不能穿墙。
- 一次最多向上一格（跳跃），向下按重力下落。
- 水中、灵魂沙、蜘蛛网等地形按原版减速。
- 挖掘和放置走原版流程（挖掘时间、工具、附魔、耐久）。

### 8.2 两层规划

1. **粗略路线**：以区块为单位，根据地表高度图和已知障碍（海洋、峡谷、岩浆湖），生成每隔 10～20 格一个的路标。
2. **局部 A***：在机器人周围 15×15×15 的范围内，算出到下一个路标的精确路线。每走几步重新算一次，被堵住就立刻重算。

### 8.3 动作和代价

| 动作 | 代价 |
|---|---|
| 平走、斜走 | 走路耗时 |
| 上一格 | 走路 + 跳跃 |
| 下落 | 按模式限制高度 |
| 挖穿 | 原版挖掘时间（取决于背包里最合适的工具） |
| 搭路、垫高 | 放置耗时，需要背包里有方块 |

### 8.4 三种模式

| | 保守 safe | 正常 normal | 激进 aggressive |
|---|---|---|---|
| 最大下落高度 | 3 格（无伤害） | 3 格 | 不超过 1/3 血量的伤害 |
| 疾跑 | 否 | 是 | 是 |
| 挖穿开路 | 代价高，优先绕路 | 正常 | 代价低，优先直线 |
| 跳跃跨越空隙 | 否 | 1 格 | 1～2 格 |
| 离岩浆的安全距离 | 2 格 | 1 格 | 只要不相邻 |

### 8.5 卡住处理

- 来回打转：选定路线后先走几步；走过的位置会增加代价。
- 一段时间没有进展：换个方向重算 → 扩大搜索窗口 → 让粗略路线换一条 → 停下来汇报。

### 8.6 鞘翅（后续阶段）

在直接控制坐标的前提下，鞘翅长途飞行反而比走路简单：沿地表高度图保持安全高度飞行，速度按原版"鞘翅 + 烟花"的上限计算，消耗鞘翅耐久和烟花（都由玩家提供）。起飞和降落是难点，放在第 4 阶段。

## 9. 保护体系

1. **保护区块**：玩家站在区块里输入 `/bot protect` 就整块（从基岩到天空）受保护。机器人可以路过，但在里面是"灵魂状态"（原版旁观者模式，仍按自己的碰撞走路、不穿墙）：不挖、不放、不捡、不打、不交互，不触发机关，怪不盯它。（2026-11-02 起取代原来填坐标的长方体保护区。）
2. **全局移动禁区**：寻路时把以下方块视为不可通行或不可踩踏——压力板、绊线、幽匿感测体、耕地、红石元件、门、按钮、拉杆、传送门，以及岩浆、火。
3. **放置记录**：从安装模组起记录所有玩家放置的方块，机器人一律不挖。
4. **操作日志和撤销**：记录机器人破坏的每个方块，可以一键还原。
5. **种子比对（可选，后续阶段）**：用种子重新生成区块，和当前方块逐个比对，只挖原生方块。

所有挖掘、放置、交互操作在执行前都必须经过守卫检查，**守卫在服务端强制执行，和寻路逻辑无关**。

## 10. 开发阶段

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| **0. 原型** | 假人、背包编辑、局部 A* + 坐标移动、保护区、`/bot get water_bucket` | 单人存档里：给它空桶 → 它自己走到最近的水源，绕开障碍、必要时挖穿 → 装满水 → 走回来 |
| 1. 地表采集 | 粗略路线、挖掘任意方块、知识图谱、计划确认、三种模式、放置记录、撤销 | 能完成樱花树叶、錾制砂岩、火把这类任务 |
| 2. 地下 | 向下挖掘、洞穴寻路、危险撤退、找结构和群系 | 能完成矿石、垂滴叶这类任务 |
| 3. 水下 | 游泳、氧气、水下挖掘 | 能采到未枯萎的珊瑚 |
| 4. 长途 | 鞘翅、种子比对、多个机器人 | — |

## 11. 原型范围（阶段 0）

- `/bot spawn`、`/bot remove`、右键打开背包
- `/bot get water_bucket`：找到最近的水源方块 → 寻路过去 → 用空桶装水 → 回到下达任务的玩家身边
- 局部 A*：平走、上一格、下落、挖穿（使用背包里的工具，原版挖掘时间）
- 直接控制坐标移动，速度遵守原版限制
- 保护区（`/bot protect add ... here <半径>`）+ 移动禁区
- `/bot debug path` 粒子显示路线
- 苦力怕不把它当目标
