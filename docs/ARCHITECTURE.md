# HelperBot 架构

约 6800 行，36 个文件，分 5 层。**上层只调用下层，下层不知道上层的存在。**

```
 玩家
  │  /bot 指令、右键打开背包
  ▼
┌──────────────────────────────────────────────────────────┐
│ ① 入口层   HelperBot, command/BotCommands, BotInventoryMenu │  听玩家说什么
└──────────────────────────────────────────────────────────┘
  │ 创建任务
  ▼
┌──────────────────────────────────────────────────────────┐
│ ② 任务层   task/*                                          │  "要做什么"
│   AcquireTask（总指挥）→ GatherTask / HuntTask / CraftStep  │
│                          / SmeltStep / FetchWaterTask      │
└──────────────────────────────────────────────────────────┘
  │ 查资料                          │ "走到那里""挖这块""放这块"
  ▼                                 ▼
┌───────────────────────┐   ┌──────────────────────────────┐
│ ③ 知识层 knowledge/*   │   │ ④ 身体层  bot/*               │  "怎么做"
│ 东西从哪来、怎么做出来 │   │ BotPlayer：生存优先级         │
│ （只读游戏数据）       │   │ MovementController：走/挖/放  │
└───────────────────────┘   │ Loot：捡掉落物  Sight：视线   │
                            └──────────────────────────────┘
                                    │ 找路           │ 能不能挖/放
                                    ▼                ▼
                            ┌──────────────┐  ┌──────────────┐
                            │ ⑤ 寻路 path/* │  │ ⑤ 规则 guard/*│
                            └──────────────┘  └──────────────┘
```

## ① 入口层：听玩家说什么

| 文件 | 作用 |
|---|---|
| `HelperBot` | 模组启动：注册指令、右键事件，服务器启动时预热知识层 |
| `command/BotCommands` | 所有 `/bot ...` 指令，把玩家的话翻译成一个任务 |
| `bot/BotManager` | 生成、删除机器人，加载它的存档数据 |
| `bot/BotInventoryMenu` | 右键打开的背包界面 |
| `bot/FakeConnection` | 假的网络连接（机器人没有客户端） |

## ② 任务层：要做什么

每个任务每帧被调用一次，返回"还在做 / 做完了 / 失败了"。

| 文件 | 作用 |
|---|---|
| `AcquireTask` | **总指挥**。`/bot get` 用它：问知识层要一份计划，一步步执行，每做完一步重新规划 |
| `GatherTask` | 找到某种方块，走过去，挖之前核对手里的东西，挖（掉落物交给 Loot） |
| `HuntTask` | 找到会掉这种东西的生物，追上去打死（捡掉落物交给 Loot）。找不到时按生物怎么出现来办：动物先去 1000 格内最近的"它最多的群系"（按原版生成数据算出哪些群系最多），没有就在 500 格内按群系密度挑地方找，怪物找黑暗处等（白天露天就等天黑），特殊生物直接说明 |
| `CraftStep` / `SmeltStep` / `Station` | 合成、熔炼；需要时自己放工作台/熔炉，用完收回 |
| `FetchWaterTask` | 打一桶水（特殊：要找水面） |
| `ComeTask` | `/bot come`：走到玩家身边 |

## ③ 知识层：东西从哪来（不动世界，只读游戏数据）

| 文件 | 回答的问题 |
|---|---|
| `DropAnalysis` | 挖哪种方块会掉这个东西？用什么工具？ |
| `MobDrops` | 打哪种生物会掉这个东西？它在哪些群系出生？ |
| `RecipeIndex` | 哪些配方能做出这个东西？ |
| `CraftPlanner` | 综合以上，**算出最省事的计划**（挖/打/合成/熔炼的顺序） |
| `BiomeHints` / `BlockScanner` | 附近有没有？哪个群系会生成？ |
| `Obtainability` | 这东西生存模式能拿到吗？（基岩、命令方块直接拒绝） |

## ④ 身体层：怎么做

### BotPlayer：每帧的优先级（最重要的一张表）

每帧从上往下问，**谁说"我在忙"，下面的就都不执行**：

| 顺序 | 层 | 什么时候接管 |
|---|---|---|
| 1 | 换气 `breathe` | 水下快没气了 |
| 2 | 自卫 `combat` | 有怪在打它（远程 10 格内 / 近战够得着） |
| 3 | 吃东西 `tryEat` | 饿了（边走边吃） |
| 4 | 捡掉落物 `Loot` | 任务挖掉的方块、打死的怪掉了它要的东西（按"出现时间"跟踪，飘走、滚远都认得；水下先不追正在上浮的，到水面再一起捡） |
| 5 | 整理背包 `tidyInventory` | 背包快满了 |
| 6 | 任务 `task.tick` | 以上都没事 |
| — | 移动 `movement.tick` | 每帧最后执行，真正挪动身体 |

上层（自卫、捡东西）要临时去别的地方时，用 `engage` 借用移动；结束时用 `disengage` 把任务原来的目的地还回去。

### MovementController：身体（最大、bug 最多的文件）

| 部分 | 作用 |
|---|---|
| 走路 | 按路径一步步走：迈步、跳、下落、游泳；速度、跳跃高度、重力都按原版限制 |
| 挖/放 | 走原版的"挖方块""右键放方块"流程 |
| 卡住处理 | 原地不动检测、记住挡路的格子并绕开、扩大搜索、贴墙滑动 |
| 收方块 | 没路可走时就地挖些方块，用来搭桥、垫柱子 |

## ⑤ 底层

| 文件 | 作用 |
|---|---|
| `path/LocalPathfinder` | A* 寻路：在一块范围内找一串"走/跳/挖/搭桥/垫柱/游泳"的步骤；水下每个节点还带着"剩余空气" |
| `path/Air`, `path/Escape` | **水下的唯一规则**：空气预算（剩余空气 + 允许扣的血）必须够它从当前位置出水；`Escape` 算"从这格到能呼吸要多少帧"（含水下挖方块的真实速度、掉落的沙子）。寻路、换气、选目标都用它 |
| `path/Mode` | 安全 / 普通 / 激进三种模式的参数 |
| `path/BreakTimes`, `BuildingBlocks` | 挖一块要多久；哪些方块可以拿来搭路 |
| `guard/Guard` | **能不能挖、能不能放**（所有挖和放都要先问它） |
| `guard/Rules`, `ProtectionZones` | 开放/严格规则；保护区 |
| `mixin/*` | 改原版的三处：苦力怕不炸它、睡觉不算它、捡东西前问它要不要 |

## 出 bug 时去哪找

| 现象 | 多半在 |
|---|---|
| 卡住、走歪、悬空、掉坑 | `MovementController`（执行）或 `LocalPathfinder`（规划） |
| 水下：憋气、换气、堵井口 | `BotPlayer.breathe`（什么时候、怎么换气），`Air`/`Escape`（够不够） |
| 水下：路线、目标选择 | `LocalPathfinder.airAfter`，`GatherTask.targetCost` |
| 打怪不对 | `BotPlayer.combat` |
| 东西没捡 | `Loot`（所有掉落物的跟踪和拾取）、`ItemEntityMixin`（要不要） |
| 挖了没掉东西 | `GatherTask.mine`（挖之前核对手里的东西）、`GatherTask.checkDrop`（日志里的"异常"） |
| 计划很蠢（舍近求远） | `CraftPlanner` 的成本 |
| 挖了不该挖的 | `Guard` |
| 说"找不到 / 做不了" | 知识层 |

先看 `/bot log`，里面每条都能对应到上面某一层。
